## Grammar / Грамматика

### Объяснение грамматики на русском

`Kunnen` означает физическую возможность или умение: `ik kan`, `jij kunt/kan`, `u kunt`, `hij/zij kan`, `wij/jullie/zij kunnen`. Второй глагол стоит в конце: `Ik kan de sleutel vinden.`

Порядковые числительные обычно получают `-de` или `-ste`: `tweede`, `vierde`, `achtste`, `twintigste`; формы `eerste` и `achtste` нужно запомнить. С предлогами места важно учить готовые сочетания: `op tafel`, `onder het bed`, `naast de kast`, `tegenover de supermarkt`.

### Kunnen (can, to be able to)

`kunnen` is a modal verb. It means `мочь / уметь` (can, to be able to). The second verb goes to the end as an infinitive: `Ik kan autorijden.`

| Subject | Form | Example |
| --- | --- | --- |
| ik | kan | Ik kan autorijden. |
| jij/je | kan / kunt | Jij kan autorijden. / Jij kunt autorijden. |
| inversion with jij/je | kan jij? / kun jij? | Kan jij mij helpen? / Kun jij mij helpen? |
| u | kan / kunt | U kan autorijden. / U kunt autorijden. |
| inversion with u | kunt u? | Kunt u alles vinden? |
| hij/zij/het | kan | Hij kan autorijden. |
| wij/we | kunnen | Wij kunnen autorijden. |
| jullie | kunnen | Jullie kunnen autorijden. |
| zij/ze | kunnen | Zij kunnen autorijden. |

Notes:

- Singular subjects (`ik`, `hij`, `zij`, `het`) use `kan`.
- With `jij`/`je` and `u` both `kan` and `kunt` are correct.
- Plural subjects (`wij`, `jullie`, `zij`) use `kunnen`.

### Ordinal Numbers (rangtelwoorden)

Ordinal numbers say the position: first, second, third ...

| Number | Ordinal | Number | Ordinal |
| --- | --- | --- | --- |
| 1e | eerste | 10e | tiende |
| 2e | tweede | 11e | elfde |
| 3e | derde | 20e | twintigste |
| 4e | vierde | 21e | eenentwintigste |
| 5e | vijfde | 22e | tweeentwintigste |
| 6e | zesde | 30e | dertigste |
| 7e | zevende | 40e | veertigste |
| 8e | achtste | 50e | vijftigste |
| 9e | negende | 60e | zestigste |

Higher ones: `70e zeventigste`, `80e tachtigste`, `90e negentigste`, `100e honderdste`, `1000e duizendste`.

Rules:

- Numbers 1-19 (and their "-teen" style forms) add `-de`, with exceptions: `eerste`, `achtste`, `derde`.
- Numbers from 20 up add `-ste`: `twintigste`, `dertigste`, `honderdste`.
- Used for dates and order: `Januari is de eerste maand van het jaar.`, `Maandag is de eerste dag van de week.`

### Prepositions Of Place (preposities van plaats)

These tell where something is.

| Dutch | Meaning | Russian |
| --- | --- | --- |
| voor | in front of | перед |
| achter | behind | за, позади |
| boven | above | над |
| onder | under, below | под |
| op | on | на |
| tussen | between | между |
| naast | next to | рядом с |
| bij | by, near | у, около |
| tegen | against | у, к (вплотную) |
| tegenover | opposite | напротив |
| rond / om | around | вокруг |
| aan | on, at (hanging) | на (висит на) |

Examples:

1. De salontafel staat voor de bank.
2. Achter de tafel hangt een schilderij.
3. De stoelen staan rond de eettafel / om de eettafel.
4. De lamp hangt boven de tafel.
5. Het kleed ligt onder de salontafel.
6. De pen ligt tussen het boek en de mobiele telefoon.
7. De klok hangt aan de muur.
8. De schemerlamp staat naast de bank.
9. De lichtknop zit bij de deur.
10. De boekenkast staat tegen de muur.
11. De boekenkast staat tegenover de bank.
