## Grammar / Грамматика

### Объяснение грамматики на русском

Общий вопрос начинается с глагола: `Heb jij kinderen?` Специальный вопрос начинается с вопросительного слова, а глагол остаётся на втором месте: `Waar woon jij?`, `Hoe heet hij?`. После глагола перед подлежащим возникает инверсия.

Глагол `hebben` («иметь») спрягается так: `ik heb`, `jij/je hebt`, `u hebt/heeft`, `hij/zij/het heeft`, `wij/jullie/zij hebben`. При инверсии с `jij` окончание `-t` исчезает: `Jij hebt ...`, но `Heb jij ...?`

### Question Sentences

The lesson introduces several types of Dutch questions.

#### Yes/no Questions

In yes/no questions, the conjugated verb usually comes first.

Examples:

1. Ben jij Alex?
2. Woon je in Nederland?
3. Heb jij een auto?
4. Spreek je Nederlands?

#### Questions With Question Words

Question words come first, followed by the conjugated verb.

Examples:

1. Wie ben je?
2. Wat is je naam?
3. Waar woon je?
4. Waar kom je vandaan?
5. Wanneer werk je?
6. Hoe oud ben je?
7. Hoeveel talen spreek je?
8. Welke talen spreek je?

Useful question words:

| Dutch | English | Russian |
| --- | --- | --- |
| wie | who | кто |
| wat | what | что |
| waar | where | где, куда |
| waar vandaan | from where | откуда |
| wanneer | when | когда |
| hoe | how | как |
| hoeveel | how much, how many | сколько |
| welke | which | какой |

### Hebben

`Hebben` means "to have".

| Subject | Form |
| --- | --- |
| ik | heb |
| jij/je | hebt |
| heb jij/je? | heb |
| u | hebt / heeft |
| hij/zij/het | heeft |
| wij/we | hebben |
| jullie | hebben |
| zij/ze | hebben |

Examples:

1. Ik heb een auto.
2. Jij hebt een fiets.
3. Heb jij een zus?
4. U heeft een auto.
5. Hij heeft een broer.
6. Wij hebben kinderen.
7. Jullie hebben veel huiswerk.
8. Zij hebben drie boeken.

### Word Order In Questions

Common patterns:

| Type | Pattern | Example |
| --- | --- | --- |
| yes/no question | verb + subject + rest | Heb jij een fiets? |
| question word | question word + verb + subject + rest | Waar woon jij? |
| answer | subject + verb + rest | Ik woon in Almere. |
