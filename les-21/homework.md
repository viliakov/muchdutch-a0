## 3. Запишите предложения с одним и двумя глаголами

Сначала поставьте разделяемый глагол в настоящее время. Затем добавьте указанный глагол и напишите инфинитив слитно.

1. `ik / de keuken / schoonmaken` → `gaan`
2. `ik / om 14.23 uur / aankomen` → `willen`
3. `jullie / broodjes / meenemen` → `willen`
4. `hij / de pannenkoek / omdraaien` → `moeten`
5. `ik / de spullen morgen / opsturen` → `kunnen`
6. `het kind / de weg / oversteken` → `mogen`
7. `de docent / de opdracht / uitleggen` → `gaan`
